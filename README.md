# Анализ финансовых транзакций и клиентов

## Описание проекта
Тестовое задание для стажировки в группу анализа данных.

**Стек:** Python, pandas, numpy, matplotlib, seaborn, scikit-learn

## Что включала в себя работа:

### 1. Очистка и подготовка данных
- Преобразование дат, обработка `INVALID_DATE` (10% пропусков, оставлены как NaT)
- Обработка пропусков в `transaction_id`, `client_id`
- Анализ категорий "Неизвестная услуга", "Неизвестно" в payment_method
- Анализ "Неизвестный город" и "Неизвестный консультант"
- Обработка клиентов: удалены пропуски в `net_worth`, заполнены пропуски в `age` (медиана), `gender` заменен на "Неизвестно"
- Есть закономерность: консультанты Jordan Phillips и Laura Herrera чаще всех работают с "Неизвестный город"

### 2. Анализ данных
- **Топ-5 услуг** по количеству заказов:
  - Инвестиционное консультирование - 2 429
  - Управление активами - 2 014
  - Финансовое планирование - 1 532
  - Налоговое планирование - 1 528
  - Структурирование капитала - 1 507
- **Средняя сумма по городам**: максимальная в Port Michellemouth, минимальная в East Jamie
- **Услуга с наибольшей выручкой** - Инвестиционное консультирование (115 млн руб.)
- **Процент транзакций по способам оплаты**:
  - Кредитная карта - 40%
  - Банковский перевод - 34.6%
  - Неизвестно - 10.1%
  - Наличные - 9.9%
  - Криптовалюта - 5.4%
- **Выручка за последний месяц** (март 2025) - 105,3 млн руб. (неполный месяц)

### 3. Объединение с клиентами и анализ по уровням активов
- **Результаты**:
  - Высокий капитал (>1M) - 80.6% транзакций, 81.1% выручки
  - Средний капитал (100k-1M) - 17.6% транзакций, 17.1% выручки
  - Низкий капитал (<100k) - 1.9% транзакций, 1.8% выручки
  - Средний чек во всех группах одинаков (48-49 тыс. руб.), то есть разница либо в кол-ве клиентов, либо в кол-ве транзакций

### 4. Визуализация
- Распределение сумм транзакций
- Выручка по услугам
- Зависимость среднего чека от возраста (корреляции нет)

### 5. Прогнозирование
- Линейная регрессия (из-за малого кол-ва данных предполагаю линейный тренд)
- Прогноз выручки на апрель 2025 - 75 млн руб.
